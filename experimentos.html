24 experimentos posibles, ordenados por qué validan y cuánto cuesta ejecutarlos. Menciones breves — úsalos como banco de ideas al armar tu Experiment Backlog.

Recurso anexo
Bajo costo — validar rápido y barato Costo medio/alto — mayor fidelidad y compromiso

01 · Validación de Problema y Demanda

Confirman que el dolor existe, es relevante, y que hay interés real antes de diseñar cualquier solución.

Bajo costo

Fake Door Test

Un botón, anuncio o landing hacia una función que aún no existe, para medir cuántos usuarios intentan usarla.

Caso real: Dropbox →
Bajo costo

Painted Door Test

Variante del Fake Door ejecutada dentro de un producto ya en uso, sin salir del flujo habitual.

Caso real: Optimizely →
Bajo costo

Landing Page Test

Página de aterrizaje con la propuesta de valor y un CTA de registro para medir intención real.

Caso real: Buffer →
Bajo costo

Encuesta de Validación

Cuestionario corto y dirigido para medir frecuencia e intensidad de un problema en un segmento.

Caso real: Superhuman →
Bajo costo

Entrevista de Problema

Conversación 1:1 semiestructurada para confirmar que el dolor es real antes de hablar de soluciones.

Caso real: The Mom Test →
Bajo costo

Análisis de Señales Sociales

Monitoreo de quejas y menciones en redes, foros y reseñas como evidencia directa y no solicitada.

Caso real: Reddit listening →

02 · Validación de Solución y Prototipo

Prueban si una solución específica resuelve el problema, sin construir el producto completo de verdad.

Costo medio

Wizard of Oz

Interfaz que parece automatizada, pero una persona ejecuta el proceso manualmente detrás.

Caso real: Zappos →
Costo medio

Concierge MVP

El equipo entrega el servicio a mano, de forma transparente: el usuario sabe que no está automatizado.

Caso real: Food on the Table →
Bajo costo

Mechanical Turk

Una persona reemplaza a la tecnología compleja (voz, IA) que aún no está construida, sin que el usuario lo note.

Caso real: Facebook M →
Costo medio

Prototipo Interactivo

Simulación clicable en Figma, Bolt o Lovable, sin backend real, para validar el flujo antes de programar.

Caso real: Figma →
Bajo costo

Test de Usabilidad Moderado

Observar a un usuario intentando resolver una tarea real sobre el prototipo, en vivo.

Caso real: NN/g →
Bajo costo

Five-Second Test

Mostrar un diseño 5 segundos y preguntar qué recuerda el usuario — mide impacto de primera impresión.

Caso real: Smashing Magazine →
Bajo costo

First-Click Test

Registrar dónde hace clic primero el usuario ante una tarea — revela si la interfaz comunica bien.

Caso real: SFG20 →
Bajo costo

Card Sorting

Los usuarios agrupan contenido a su manera para informar cómo estructurar la arquitectura de información.

Caso real: NN/g →
Bajo costo

Tree Testing

Validar si una estructura de navegación ya definida permite encontrar las cosas sin pistas visuales.

Caso real: NN/g →

03 · Validación de Modelo de Negocio y Precio

Miden disposición a pagar y viabilidad económica antes de invertir en construir a escala.

Costo medio

Smoke Test

Landing con precio y botón de "comprar" o "reservar" para medir intención de compra real.

Caso real: Buffer →
Costo alto

Crowdfunding / Preventa

Cobrar (o pre-vender) antes de construir — la validación más dura: dinero real sobre la mesa.

Caso real: Pebble →
Bajo costo

Carta de Intención (LOI)

Compromiso no vinculante de un cliente B2B, útil para validar demanda antes de firmar contratos.

Caso real: Learning Loop →
Costo medio

Test de Precios A/B

El mismo producto a distintos precios por segmento, para encontrar el punto óptimo de conversión.

Caso real: HubSpot →

04 · Validación de Crecimiento y Retención

Se ejecutan con el producto ya construido, para optimizar activación, retención y expansión con evidencia cuantitativa.

Costo alto

A/B Test

Comparar dos variantes contra una métrica objetivo, con significancia estadística antes de decidir.

Caso real: Google →
Costo alto

Multivariate Test

Probar varias variables al mismo tiempo para entender su efecto combinado sobre el resultado.

Caso real: Amazon →
Costo medio

Feature Flag Rollout

Activar una función solo para un porcentaje de usuarios reales antes de liberarla a todos.

Caso real: LaunchDarkly →
Bajo costo

Beta Program / Dogfooding

Uso interno del equipo o con early adopters seleccionados antes del lanzamiento masivo.

Caso real: Microsoft →
Bajo costo

Email Drip Campaign

Secuencia de correos que simula un producto para medir interés y conversión sin construir nada.

Caso real: Brevo →
