01Prompt

La instrucción del experimento

Aplicado a diseño de experimentos

Un prompt vago genera experimentos genéricos. Un prompt con rol, restricción de costo y formato de salida genera un Experiment Backlog directamente accionable.

"Dame ideas para validar esto" → genérico · "Eres PM de una fintech. Dame 8 experimentos para validar [hipótesis], ordenados de menor a mayor costo, con criterio de éxito medible para cada uno" → útil
El PM lo aplica cuando…
Especifica el rol, el supuesto exacto a validar, el presupuesto disponible y el formato esperado antes de preguntar.

02Context

La evidencia acumulada

Aplicado a research previo y resultados históricos

La IA no sabe qué experimentos ya corrió tu equipo si no se lo dices. Cargar el historial de experimentos anteriores evita repetir validaciones y permite detectar patrones entre sesiones.

Subir el Informe de Insights del Módulo 3 + los experimentos previos → la IA prioriza supuestos ya en tensión con evidencia real, no genéricos de industria
El PM lo aplica cuando…
Carga el Experiment Backlog acumulado, los insights de investigación y los datos de uso antes de diseñar el próximo experimento.
NotebookLMClaude (archivos)Gemini Gems
03Intent

El objetivo de la validación

Aplicado a la audiencia de la decisión

¿Vas a usar el resultado para decidir internamente en el squad, o para presentar al comité ejecutivo? El intent cambia qué tan riguroso debe ser el experimento y cómo se comunica el resultado.

"Este experimento es para decidir si matamos la feature esta semana" → la IA prioriza velocidad de señal sobre completitud estadística
El PM lo aplica cuando…
Declara explícitamente para qué decisión sirve el experimento antes de diseñarlo: "esto decide roadmap del próximo sprint", "esto va al comité ejecutivo".
GammaClaudeChatGPT
04Especificación

El formato de la métrica

Aplicado a criterios de éxito

Definir el formato del criterio de éxito — umbral numérico, ventana de tiempo, segmento — elimina ambigüedad al momento de decidir Persevere/Pivot/Kill.

"Responde con: Métrica | Umbral de éxito | Ventana de medición | Segmento objetivo. Máximo 4 filas." → criterio listo para monitorear en el dashboard
El PM lo aplica cuando…
Siempre especifica unidad, umbral y ventana de tiempo antes de lanzar el experimento — ahorra discusiones post-resultado.

05Conexión

El pipeline completo

Aplicado a automatización de experimentos

El mayor salto de productividad ocurre cuando las herramientas se conectan entre sí: Typeform recolecta → n8n dispara → Claude sintetiza → Mixpanel mide → Notion documenta la decisión. El PM orquesta el flujo completo.

Fake Door publicado → Typeform recolecta intención → n8n dispara alerta al alcanzar 100 respuestas → Claude sintetiza el resultado → Notion registra la decisión Persevere/Pivot/Kill
El PM lo aplica cuando…
Diseña el pipeline de datos del experimento: define qué entra, qué herramienta procesa, qué sale y dónde se documenta la decisión.

⚡ Principio clave

Un experimento es tan riguroso como el pipeline que lo sostiene

Un equipo que conecta las 5 capas obtiene un Experiment Backlog que aprende solo, semana a semana. El trabajo de diseñar el pipeline no es un extra — es parte del método científico aplicado a producto.

Pipelines de automatización — de la teoría a la práctica

Tres formas de construir el pipeline de experimentación según el perfil técnico del equipo.

OPEN SOURCE · TÉCNICO

n8n

Automatización de flujos visuales con nodos conectables. Integra cualquier herramienta con API — incluyendo Claude, Notion, Google Sheets, Slack.

Flujo ejemplo: Typeform (intención) → n8n → Claude API (síntesis) → Notion (Experiment Backlog) → Slack (notifica decisión)

SAAS · NO TÉCNICO

Make

Similar a n8n pero con interfaz más visual y menor curva de aprendizaje. Ideal para squads sin perfil técnico que quieren automatizar sin instalar nada.

Flujo ejemplo: Google Forms (Smoke Test) → Make → ChatGPT (extrae señal) → Sheets (registra) → Gmail (avisa al PM)

GRATUITO · INTEGRADO

Google Workspace Studio

IA de Gemini integrada directamente en Sheets, Docs y Slides. El punto de entrada más rápido a automatización si el equipo ya usa Workspace.

Flujo ejemplo: Resultados en Sheets → Gemini analiza → genera resumen en Docs → crea slide de recomendación en Slides
